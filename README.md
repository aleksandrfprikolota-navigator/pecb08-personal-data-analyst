# Data Assistant

Веб-чат личного финансового аналитика данных. Интерфейс на FastAPI, Jinja2 и HTMX. Модель читает таблицы и изображения через OpenAI API, а графики, DOCX-отчёты и markdown-сводки строятся локально и сохраняются как файлы.

## Что умеет

- принимать текстовые сообщения;
- загружать CSV, Excel, JSON и изображения;
- разбирать выручку, маржу, заказы и структуру продаж;
- строить графики `line`, `bar`, `histogram` и `pie` в PNG;
- собирать DOCX-отчёты;
- сохранять markdown-summary;
- показывать и скачивать артефакты прямо из чата.

Круговая диаграмма суммирует числовой столбец по категориям. Для `examples/sample_sales.csv` запрос «построй круговую диаграмму выручки по категориям» даёт доли `revenue` по `category`.

## Переменные окружения

Скопируйте шаблон и подставьте ключ:

```bash
Copy-Item .env.example .env
```

| Переменная | Назначение |
| --- | --- |
| `APP_NAME` | Название приложения |
| `APP_HOST` | Адрес прослушивания. `0.0.0.0` нужен, чтобы контейнер принимал запросы не только изнутри себя |
| `APP_PORT` | Порт на хосте и в контейнере, по умолчанию 8000 |
| `MAX_FILE_SIZE` | Лимит загрузки, например `10MB` |
| `UPLOAD_DIR` | Каталог входящих файлов |
| `OUTPUT_DIR` | Каталог графиков, отчётов и сводок |
| `LOG_LEVEL` | Уровень журнала |
| `OPENAI_API_KEY` | Ключ API модели |
| `OPENAI_BASE_URL` | Адрес API, по умолчанию `https://api.openai.com/v1` |
| `OPENAI_MODEL` | Имя модели |
| `OPENAI_MAX_HISTORY_MESSAGES` | Сколько последних сообщений уходит в запрос |

Файл `.env` и каталог `storage` в репозиторий не входят.

## Локальный запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Откройте `http://127.0.0.1:8000`.

## Docker

```bash
docker compose up --build -d
```

Контейнер называется `data-assistant`. Остановка: `docker compose down`.
